# Cloud Command Centre

Create a modern, premium, responsive personal portfolio website for **Emeka Edward Amanze**, a DevOps, DevSecOps, Site Reliability Engineering and Cloud Engineering professional based in Lagos, Nigeria.

The website should communicate senior-level technical capability, operational leadership, cloud engineering experience and a strong focus on security, automation, reliability and measurable business outcomes.

## Overall Creative Direction

Design the website as a modern cloud engineering command centre rather than a generic developer portfolio.

The visual experience should feel:

* Professional and technically sophisticated
* Modern, interactive and visually engaging
* Clean, organised and easy to navigate
* Secure, reliable and enterprise-focused
* Suitable for recruiters, hiring managers, engineering leaders and potential consulting clients

Use a **dark theme by default**, with a small, elegant theme-selection button in the navigation that allows visitors to switch between dark and light modes.

Persist the selected theme in the browser so the visitor’s preference remains active when they return.

### Dark Theme

Use a deep navy, charcoal or near-black background with:

* Electric blue accents
* Cyan highlights
* Subtle purple gradients
* Soft glowing borders
* Muted slate text
* White headings
* Subtle grid or infrastructure-pattern backgrounds

### Light Theme

Use a clean off-white or very light grey background with:

* Deep navy headings
* Blue and cyan accents
* Soft grey cards
* Subtle shadows
* Strong text contrast

Avoid excessive neon effects. The design should remain professional and suitable for enterprise technology roles.

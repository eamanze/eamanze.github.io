# DevOps / SRE / Cloud Engineer Portfolio

A vibrant, responsive, interactive portfolio built with plain HTML, CSS and JavaScript. It is ready to host on GitHub Pages and requires no build tool.

## Included sections

- Home
- About
- Skills
- Certifications
- Experience
- Projects with category filters
- Incident and change management workflows
- Agile delivery and cross-functional collaboration
- Resume
- Contact

## Features

- Responsive desktop, tablet and mobile layout
- Dark/light theme toggle
- Animated role typing effect
- Scroll-reveal animations
- Active navigation highlighting
- Mobile navigation menu
- Project filtering
- Static contact form that opens the visitor's email application
- Accessible semantic HTML and reduced-motion support

## Publish with GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Copy `index.html`, `styles.css`, `script.js` and the `assets` folder into the repository root.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Visit `https://YOUR-USERNAME.github.io` after deployment completes.
